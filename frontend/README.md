# Привал — фронтенд

React (Vite + TypeScript) фронтенд для QR-заказа со стола. Пока без бэкенда: все данные (меню, заказы) хранятся в `localStorage` браузера через слой `src/shared/api/*` — при подключении бэкенда меняется только реализация этих функций, остальной код не трогаем.

## Запуск

```bash
npm install
npm run dev
```

Гостевая часть: `http://localhost:5173/?table=3`
Админка: `http://localhost:5173/admin` (код доступа по умолчанию — `privaladmin`, см. `.env.example`)

## Структура

```
src/
  app/            роутинг
  pages/guest/    меню, корзина, оформление заказа, экран успеха
  pages/admin/    заказы, меню, QR-коды столов, отчёты
  widgets/        составные блоки экрана (карточка блюда, нижняя панель корзины и т.д.)
  entities/       доменные сущности (блюдо, меню)
  shared/         типы, mock-API, конфиг, переиспользуемый UI-кит
  store/          zustand-стор корзины
  mocks/          сид-данные меню (из реального меню кафе)
```
